Guide Questions: ● Which game activity consumed the most CPU resources? Game activities such as animations, player interactions, and processing game objects consumed CPU resources. ● Why do you think CPU usage increased? CPU usage increased because the processor was handling game calculations, animations, controls, sounds, and other processes required to run the game. ● How does CPU performance affect the gameplay experience? CPU performance affects how quickly the game processes actions and responds to the player. Good CPU performance helps make gameplay smoother and more responsive. B. Part IV. Operating System Analysis Answer the following questions.

  1. Which operating system services were used while playing the game? Discuss each of the following where applicable. ● Process Management: The OS managed the game and background apps such as Chrome and Facebook. ● Memory Management: The OS provided memory for the game and other running applications. ● File Management: The OS loaded the game's files, graphics, sounds, and other data. ● Device Management: The OS managed the CPU, GPU, screen, touch controls, and Wi-Fi. ● CPU Scheduling: The OS shared CPU resources between the game and background applications.
  2. How did the operating system manage multiple applications simultaneously? Support your answer using observations from Task Manager or Activity Monitor. The operating system allowed the game to run while other applications such as Chrome, Facebook, Giggle Academy, and Game Space remained open. It managed the phone's resources so the applications could run at the same time.
  3. What evidence shows that the operating system manages hardware resources while the game is running? I observed 48% CPU utilization, 25% GPU utilization, and 55 FPS while playing the game. These values show that the operating system was managing the phone's CPU and GPU resources to run and display the game.
  4. Would the game function properly without an operating system? Explain your answer. No. The game would not function properly without an operating system because the OS manages the phone's hardware, memory, storage, and applications. It allows the game to communicate with the CPU, GPU, screen, and other hardware.

  1. If your game consumed excessive CPU resources, what improvements would you recommend? We would optimize the game code, reduce unnecessary calculations, and improve the game's animations and background processes. We would also optimize scripts so the CPU does not have to process unnecessary tasks.

  2. If your game consumed excessive RAM, how could memory usage be optimized? We would reduce the size of textures and game assets, remove unused resources, and properly manage memory. We would also avoid loading too many game assets at the same time.

  3. Would lowering graphics settings improve performance? Explain why. Yes. Lowering graphics settings can reduce the workload on the GPU and CPU. This can improve FPS, reduce frame drops, and make the game run more smoothly.

  4. Which hardware component appears to have the greatest impact on your game's performance? Justify your answer. The GPU appears to have a major impact because it is responsible for rendering the game's graphics, animations, and visual effects. Our observation showed 25% GPU utilization while the game was running.

  5. If you were releasing this game commercially, what minimum hardware specifications would you recommend to players? Explain your recommendations. We would recommend: ● Processor: Octa-core processor ● RAM: 4 GB minimum ● Storage: At least 64 GB available storage ● GPU: Mali-G57 or equivalent ● Operating System: Android 11 or newer ● Internet: Wi-Fi or mobile data when an internet connection is required

Project Reflection After completing today's investigation, answer the following. ● Did your group identify any changes needed in your capstone project? Yes. Our group identified the need to optimize BlockPlay for Android devices by keeping the 3D graphics, animations, and game assets efficient. We also decided to include microphone support for voice-based educational activities. ● Do your target users have sufficient hardware to run your proposed application? Yes, as long as their Android devices meet the minimum requirements. The project is designed to run on low-end to mid-range devices with at least 4 GB of RAM and a compatible GPU. However, older devices may experience lag or longer loading times. ● Would you simplify or expand your project based on today's lesson? Explain. We would simplify and optimize some parts of the project rather than expanding it unnecessarily. Since BlockPlay is a 3D educational game, we will focus on essential 3D features, efficient graphics, and offline functionality to keep the game accessible while maintaining a good learning experience.

Part VII. Individual Reflection Write an individual reflection consisting of 250 to 300 words. Guide Questions: ● What is the most important concept you learned about operating systems? The most important concept I learned about operating systems is how they manage and control the resources of a device while an application is running. I learned that process management, memory management, file management, device management, and CPU scheduling are important because they allow the game and other applications to work properly at the same time. The operating system makes sure that the CPU, RAM, GPU, storage, touchscreen, and other hardware are properly used. ● How does the operating system influence software performance?

The operating system greatly influences software performance because it manages how much of the device's resources are given to each application. During our investigation, we observed CPU and GPU utilization and recorded 55 FPS while playing the game. This helped me understand that the operating system plays an important role in keeping the game responsive and running smoothly. Background applications can also use resources, which may affect the performance of the game. ● What surprised you most during the investigation? What surprised me most during the investigation was how many operating system resources are involved even when running an educational game. I initially thought that a simple game would not require much CPU, GPU, or memory usage. However, I learned that the operating system continuously manages these resources while the game is running, even when other applications are open in the background. Monitoring the CPU, GPU, and FPS helped me understand how hardware performance can directly affect the gaming experience. ● How will this lesson help your group develop a better capstone project? This lesson will help our group develop a better capstone project by teaching us how important optimization is, especially for an Android 3D educational game like BlockPlay. We can apply what we learned by reducing unnecessary processes, optimizing 3D assets and animations, managing memory properly, and keeping the game's hardware requirements accessible to low-end and mid-range devices. It also helped us understand the importance of offline functionality and microphone support for our planned educational activities.
