Chainy project documentation​

Capstone project title: Chainy: A 3D World Educational Game for learning emerging Technology (Blockchain & AI)

Source of truth: governing mission and scope. Deliver offline foundational Web3, AI and blockchain learning for ages 12–17, especially underserved and remote communities. The approved tappable map and selected foundations supersede required exploration, free construction and full A–Z coverage.

The public documentation library renders all project Markdown with search, categories and historical notices. The source repository remains private. See viewer operations for publishing and maintenance.

This is the project's design and delivery reference, prepared October 5, 2026 before game implementation. Start with the confirmed baseline, then use the relevant specification and your assigned work packet. Detailed design choices marked proposed are reviewable recommendations; their presence in a document does not make them tested or school-approved.

Documentation first with a finite review​

Review this specification now; record accepted changes and unresolved blockers on CH-02. A proposed two-day design-review window protects the October 9–11 device spike. Full documentation first means the team shares an actionable design before production; it does not require writing unobserved results before a prototype exists. A request for a major mechanic change reopens affected contracts rather than forcing a rewrite of every document.

A document is ready for implementation when its rules/interfaces, owner and acceptance checks are clear, and remaining unknowns are bounded tests. School submission readiness additionally requires verified literature, required approvals, actual build results and pilot evidence. This package does not claim those are complete.
