Chainy role Kanban and Gantt plan​

Revised October 12, 2026. Fixed beta: November 3–6 at Tambunan National High School, Marinduque. Fixed pre-final: November 21, 2026.

Use this page to understand the agreed outputs and dependencies. Use the live team board to move cards, edit dates and see history. The quick guide explains the controls. GitHub issues receive the execution copy.

Kanban: how cards move​

TodoIn ProgressDone
Named lead, clear output and prerequisites identifiedLead is working; a blocker is recorded if work cannot continueOutput linked, acceptance checked and reviewer named

Lead delivers; Support supplies agreed help; Reviewer checks the result. Dependency means another output must be ready first. Blocked means a named missing input prevents the next step. Milestone means a checkpoint or event.

Keep one main production card active per person where practical. Use issue text for blockers; the current board uses three status columns. Write a short update: completed output, next action, blocker, evidence link.
