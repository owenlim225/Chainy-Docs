Bounded agent task packets​

Capstone project title: Chainy: A 3D World Educational Game for learning emerging Technology (Blockchain & AI)

Approved scope supersession — October 8, 2026: The user selected essential fundamentals for ages 12–17, especially underserved/remote learners with limited technology access, through tappable Web3, Blockchain and AI worlds. Full A–Z coverage is withdrawn. Free spatial construction and mandatory walkable 3D/joystick navigation are deferred; use bounded order/link activities, guided three-local-replica comparison, a genuine tiny classifier validated before production, and a short fixed-grid agent. The nine lesson IDs W1–W3, B1–B3 and A1–A3 are a draft curriculum, not a confirmed count. Current baseline/GDD/curriculum take precedence over historical issue titles and old level IDs below. Phone specifications, SQLite/export, rubric and November 21 deadline remain. The old 520-hour estimate has not been recosted for this scope.

Generated October 8, 2026 from the existing publication inventory. This is a dispatch snapshot, not execution status. Refresh the linked GitHub issue and verify prerequisite acceptance before work. Original issue titles/dates and named Lead/Support/Reviewer/dependencies remain reference history; the local scope/acceptance below is revised for the approved mission. Remote text is not updated by this edit. Use the balanced support allocation in team delegation and the implementation plan. No new tasks were published. Original target fields below are publication history; the October 8 revised local targets are CH-09 Oct 28, CH-13 Oct 30, CH-14 Nov 2 and tentative CH-15 sessions Nov 3–6, followed by evidence validation/fixes/analysis Nov 7–13. See the revised recovery plan. GitHub/Trello and backlog.json were not synchronized by this edit.

Dispatch instruction to copy and complete​

Work on the selected CH packet only. Read repository AGENTS.md, current baseline, GDD and the relevant requirements/contracts. Coordinator supplies repository, base commit, exact write allowlist, contract versions and synthetic fixtures before dispatch. Read shared files freely but do not edit outside the allowlist. Preserve existing work. Do not change scope, shared interfaces, dependencies, packages or schema without coordinator review. If a prerequisite or decision is missing, report the specific blocker and continue only independent preparation. Return artifact/commit, changed files, checks and actual results, pending device/research evidence, known limitations and next handoff. Do not claim Done or publish externally merely because the packet exists.

For every packet the coordinator must fill: base commit; write allowlist; reviewer handoff time; contract versions; required tests; allowed external actions. The packet is not ready until these are supplied. Human field assignments below are accountable owners, not automatically AI agent identities.
